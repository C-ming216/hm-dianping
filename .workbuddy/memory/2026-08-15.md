## 检查：商店类型查询板块（ShopType）

功能链路：`GET /shop-type/list` → ShopTypeController.queryTypeList() → ShopTypeServiceImpl.quryShopType()（Redis 缓存 → 查库 → 写缓存）→ Result.ok(typeList)

**结论：功能能跑，但发现问题清单：**
1. 🔴 Redis 缓存 `shop:list:type:` **无 TTL**（`set()` 没传过期时间）→ 缓存永久有效，类型数据更新后前端永远看到旧数据（缓存一致性隐患）
2. 🟠 方法名拼写错误：`quryShopType` → 应为 `queryShopType`（接口 IShopTypeService + 实现都错了）
3. 🟠 ShopTypeController 未使用 import：`com.hmdp.service.impl.ShopServiceImpl`
4. 🟡 `@Resource StringRedisTemplate stringRedisTemplate;` 缺 `private`
5. 🟡 空列表也会被永久缓存（放大问题 1）
6. 🟡 提示：ShopType 的 `@JsonIgnore` 是 Jackson 注解，hutool JSONUtil 不识别，存 Redis 的 JSON 里仍含 createTime/updateTime（对前端无影响，最终走 Jackson 序列化）

**修复方案（待用户确认）**：set 加 TTL、改名 queryShopType、删多余 import、加 private
