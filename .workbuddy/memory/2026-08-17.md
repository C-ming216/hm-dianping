
## 缓存穿透/击穿优化落地（ShopServiceImpl）

用户学习黑马课程缓存章节，两轮 review + 优化后最终版已落地并编译通过：
- 设计：queryShopById(入口, Result) → queryShopWithMutex(防击穿, Shop) → 复用 queryShopWithPassthrough(防穿透, Shop)（DRY）；tryLock/unlock 工具
- 关键要点（用户易错点）：
  1. finally 释放锁必须 `if (locked)` 判断，防止误删别人的锁
  2. 拿锁失败必须 `return queryShopWithMutex(id)` 递归重试（不能调 passthrough）
  3. 缓存必须用 `JSONUtil.toJsonStr`，不是 `StrUtil.toString`
  4. 空值标记 `""` 判断要用 `hasKey` 补一层（isNotBlank("") 为 false 会漏判）
  5. `tryLock` 用 `Boolean.TRUE.equals(flag)` 防 NPE
  6. 抢到锁后复用 passthrough = 天然 double-check（其内部第一步会再查缓存）
