# 2026-08-13

## JWT+Redis 认证代码落地 + 审核修复

用户已按 `docs/JWT+Redis企业级登录认证方案.md` 落地代码（68 源文件），出现 3 个 bug 逐个排查并修复：

### 已修复的 bug
1. **验证码正确却报"验证码错误"**：`login()` 取验证码时 key 少了 `+ phone`（`get(LOGIN_CODE_KEY)` → `get(LOGIN_CODE_KEY + phone)`），导致 cacheCode 恒 null。
2. **NPE：JwtProperties.getAccessTtl() 返回 null**：`application.yaml` 缺 `hmdp.jwt` 配置段，补齐 secret/access-ttl/refresh-ttl/issuer。
3. **提交 git 前代码审核**，发现并修复：
   - `UserController.refresh()` 漏 `@PostMapping("/refresh")` 注解（refresh 接口完全失效，MvConfig 放行了但没映射）
   - `RedisConstants.LOGIN_USER_TTL` 36000 + `TimeUnit.MINUTES` = 25 天（用户已自行改 30L）
   - `logout()` accessToken 未 strip "Bearer " 前缀 → 登出删不掉 access 白名单
   - `login()` 校验顺序反了（先查 Redis 再校验手机号）；验证码用后未删除（可重复登录）
   - 清理未用 import（HttpSession ×3、RegexPatterns）、`JwtUtils` 参数名 uerId→userId、注释"JJWT"→hutool

### 当前认证架构（已落地）
- 双 Token：Access(30min, login:token:{jti} 存 UserDTO JSON) + Refresh(7天, login:refresh:{jti} 存 userId)，轮换防重放
- 验证码：login:code:{phone}，2min TTL，登录校验后删除
- 拦截器：LoginInterceptor 验签 + 查 Redis 白名单 + UserHolder(ThreadLocal)
- JWT：hutool 内置 JWTUtil（HS256），JwtProperties 绑定 hmdp.jwt.*

### 遗留注意
- 前端调用约定：`Authorization: Bearer <accessToken>`、`x-refresh-token: <refreshToken>`
- Redis 在 192.168.90.128:6379（虚拟机），需开启
