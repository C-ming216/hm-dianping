## 输出：企业级 JWT + Redis 登录认证方案文档

用户要求基于现有 hm-dianping 项目设计一套 JWT + Redis 双 Token 登录认证方案，生成 Markdown 文档。

**已交付**：`docs/JWT+Redis企业级登录认证方案.md`

**方案核心决策**：
- JWT 库：用 hutool 内置 `cn.hutool.jwt.JWTUtil`（pom 已有 hutool-all 5.8.38），**零新增依赖**
- 双 Token：Access（30min，`Authorization: Bearer` 携带）+ Refresh（7 天，`x-refresh-token` 携带，轮换防重放）
- Redis 白名单式存储：`login:token:{accessJti}` 存 UserDTO JSON、`login:refresh:{refreshJti}` 存 userId，登出删 key = 等效黑名单
- 拦截器：改造现有 LoginInterceptor（Session → JWT+Redis 双校验），MvConfig 放行 `/user/refresh`
- 验证码：Session → Redis `login:code:{phone}`，2 分钟 TTL

**需修改文件（7 个）**：application.yaml、RedisConstants、LoginInterceptor、MvConfig、UserServiceImpl、UserController、pom.xml（无需改）
**需新增文件（3 个）**：config/JwtProperties.java、utils/JwtUtils.java、dto/LoginResultDTO.java

**项目现状确认**：当前是 Session 登录（UserServiceImpl 用 HttpSession 存 code/userDTO），UserHolder/LoginInterceptor/MvConfig 已存在，RedisConstants 已预留 `login:token:` 常量。源码用 javax.*（Java EE 8），Spring Boot 2.7.18。
